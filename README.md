# Nera - AI Infiltration Agent

> **"Every system has a flaw. Every conversation is a target. Nera is the ghost in the machine."**

Nera is a high-performance Chrome Extension designed for tactical social media infiltration. It doesn't just comment; it analyzes, synthesizes, and deploys high-fidelity AI payloads directly into the heart of the DOM.

## Core Capabilities

- **Neural Infiltration**: Seamlessly injects a **Ghost Bar UI** into Facebook, X (Twitter), and LinkedIn without triggering defensive heuristics.
- **Multi-Model Synapse**: Integrated with Groq, Gemini, and OpenAI for rapid-fire payload synthesis.
- **Persona Morphing**: Instantly switch between AI souls. Whether it's the cold efficiency of **Hawl** or the warmth of a social butterfly, Nera adapts.
- **Paranoid Stealth Engine**: Features 'Ghost Typing' with randomized delays, human-like errors, and tactical pauses to bypass automated detection systems.
- **Deep Context Extraction**: Analyzes post metadata, text, and even image/video content to ensure maximum resonance.

## Tactical Stack

- **Frontend**: Vanilla JS (ES6 Modules), Shadow DOM isolation.
- **Styling**: Premium "Blue Electron" aesthetics, high-fidelity CSS transitions.
- **Backend**: Chrome Extension V3 Architecture.
- **Intelligence**: Groq (Llama 3), Google Gemini 2.0, OpenAI GPT-4o.

## Installation Guide

1. **Source Preparation**: Clone or download the Nera project directory to your workspace.
2. **Enable Developer Mode**:
   - Open Chrome and navigate to `chrome://extensions/`.
   - Toggle **Developer mode** in the top right corner.
3. **Load the Agent**:
   - Click the **Load unpacked** button.
   - Select the root directory of the Nera project (containing `manifest.json`).
4. **Pin Nera**: Click the extensions puzzle icon on your toolbar and pin **Nera - AI Infiltration Agent** for rapid access.

## Operational Manual (Usage)

### 1. Initial Configuration
- Open the Nera **Side Panel** or **Popup** by clicking the extension icon.
- Navigate to the **Settings** section.
- Input your **API Keys** for the desired providers (Groq, Gemini, or OpenAI).
- Select your active **Persona** (e.g., Hawl, Social Butterfly) to define the response DNA.

### 2. Targeting & Infiltration
- Navigate to Facebook, X (Twitter), or LinkedIn.
- Hover over any post or comment thread.
- A **Ghost Bar** (a subtle, translucent control interface) will materialize.
- Click the Nera icon to expand the **Tactical Console**.

### 3. Payload Deployment
- **Synthesize**: Click this to trigger the AI engine. It will analyze the target's context and generate a high-resonance comment.
- **Edit**: Refine the payload directly in the console's editor if tactical adjustments are needed.
- **Launch**: Click Launch to initiate the **Ghost Typing** protocol. Nera will automatically "type" the payload into the platform's input field, mimicking human behavior.

### 4. Stealth Protocols
Adjust your infiltration signature via the Stealth settings:
- **Fast**: High-speed injection, bypassing human-simulated delays.
- **Human**: Standard interaction speed with realistic keystroke delays.
- **Paranoid**: Maximum stealth. Includes randomized typos, auto-corrections, and strategic pauses. (Highly recommended for high-security environments to evade AI detection).
